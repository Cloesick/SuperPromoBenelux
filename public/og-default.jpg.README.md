# Default OG Image Placeholder

This directory should contain `og-default.jpg` - a 1200x630px image used as the default Open Graph image for social media sharing when no folder-specific image is available.

## Requirements:
- Filename: `og-default.jpg`
- Dimensions: 1200px × 630px
- Format: JPG or PNG
- Content: SuperPromo België branding with text like "Alle supermarkt folders op één plek"

## Usage:
This image is used as a fallback in the Open Graph metadata when sharing pages on Facebook, WhatsApp, Twitter, etc.

Place the image file in: `public/og-default.jpg`
